# 桌面贴图

## 主题与材质

“设置 → 外观 → 桌面贴图 → 贴图背景”提供跟随主窗口、云母、亚克力三种选择，默认跟随主窗口。固定材质时不跟随主窗口的材质变化，明暗仍使用应用的明暗设置。

已打开的贴图监听设置和系统明暗变化。设置从数据库读取，缓存只用于首次加载，打开地址里的旧主题参数不会固定住窗口。商店主题使用云母材质回退。

`set_sticker_backdrop` 只处理当前贴图的材质，不写入主窗口的 `SettingsState.theme`。Windows 11 使用原生材质；材质不可用时保留可读的背景填充。标题栏、正文共用一个背景，无分隔线。

## 文件卡片与整图模式

- 所有文件类型默认使用 320×140 的文件卡片，显示固定 56×56 的缩略图或系统文件图标和文件名。
- 单张图片支持标题栏右上角的整图切换按钮，包括图片类型条目和单个图片文件。
- 整图模式没有正文留白或常驻标题栏，鼠标移到顶部时显示操作栏；键盘聚焦控件时也保持可见。
- 首次进入整图模式按图片比例设置窗口大小，上限 640×640，同时适配当前屏幕可用区域的 80%。小图片适度放大到可操作尺寸，极端长宽比受最小 64×64 窗口约束。
- 640×640 只限制自动计算的初始尺寸。原生窗口最大尺寸约束设置为 `null`，手动调整不设上限。保存文本和改变主题不会重置手动尺寸。
- 双击标题栏收起/展开时保留当前实际宽高；双击操作按钮不会误触收起。

## 文本编辑

文本、代码、Markdown 和链接直接在原内容元素上进入纯文本编辑，不插入文本框或编辑面板。内容与代码字体保持原样，标题栏和底部提示区的高度保持不变。

标题栏勾选按钮或 Ctrl+Enter 保存，撤销按钮或 Esc 取消。输入法组词期间不拦截这些快捷键。保存失败保留原位草稿，可再次保存；成功后才更新本地缓存。数据库读取完成前禁止编辑旧缓存内容。

## 验证与开销

`npm run test:stickers` 覆盖实际贴图组件：材质跟随/固定/重置、原生材质失败回退、原位保存/取消/失败重试、编辑布局不变、文件默认模式、图片尺寸与悬停操作栏、手动缩放不被主题更新重置，以及极小窗口中的模式开关。

主题通过事件同步，无常驻轮询。两种图片模式引用同一资源，不复制原文件；高分辨率图片仍需要图像解码内存，缩略图显示尺寸本身不等于解码内存上限。

2026-10-20 用户在更新后的 debug 版中确认主题材质、图片双模式及悬停操作栏、文本原位编辑均正常。
