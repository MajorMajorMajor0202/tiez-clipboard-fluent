便笺窗口与管理界面修复（2026-10-21）

- 独立窗口使用 `sticky-note-surface`，管理列表使用 `note-manager-card`，避免全局 CSS 同名规则互相污染。原先管理卡片的高度上限、内边距、悬停位移和强调色边框会同时作用于便笺窗口。
- 云母与亚克力通过 `set_note_backdrop` 调用原生材质，不改写主窗口主题；切换纯色时清除原生材质。不可用时保持可读的 CSS 背景。
- 标题栏在固定区域内淡入淡出，正文顶部留白保持固定。Markdown 与源码模式都不会因控件显隐移动文字。正文与控件间距缩小。
- 便笺创建时跳过任务栏，背景初始化也会修正已存在窗口的任务栏属性。
- 管理界面使用主界面相同的 Fluent 搜索框和中性按钮，卡片仅以中性色响应悬停，不上浮或突出强调色边框。

回归检查：`npm run test:notes`；生产构建及 CSP 检查：`npm run test:notes -- --release`。测试同时加载便笺窗口、管理界面和通用组件样式，覆盖原始样式冲突、材质成功与回退、显隐前后的编辑区尺寸与位置、220px 窄窗口按钮排布，以及管理界面搜索和新建操作。原生材质与任务栏行为需在 Windows debug 窗口中确认。

焦点回归修复：主窗口外部的鼠标点击仅隐藏剪贴板，不再强制激活之前的粘贴目标；普通失焦的延迟隐藏也保留 Windows 新选定的前台窗口，并跳过已经隐藏的主窗口。快捷粘贴及显式键盘隐藏仍保留原来的目标窗口恢复流程。

2026-10-21 用户在更新后的 debug 版中确认：从便笺管理新建便笺后，点击标题栏并拖动，便笺保持在前面，焦点和输入正常。


便笺折叠、停靠与快捷键（2026-10-21）

- 标题栏的折叠按钮或双击空白标题栏可切换折叠。折叠后显示第一条非空文本（去除常见 Markdown 标记），长标题省略，只保留置顶、展开、停靠、关闭控件。
- 停靠按钮或将窗口拖到当前屏幕工作区右缘可停靠。露出标题的长度按实际文字宽度计算，逻辑宽度限制为 80–220px；左侧保留圆角，右端移到屏幕外。悬停时向左伸出 32px，露出右侧关闭按钮；点击标题恢复正常窗口。关闭会等待保存，不会删除便笺。
- 折叠与停靠保留原窗口位置、展开尺寸和编辑器实例。点击停靠条恢复完整窗口；再次触发停靠快捷键恢复停靠前的展开或折叠状态。恢复后短暂抑制自动吸附，避免立即再次停靠。
- 拖动只在鼠标移动超过阈值后交给原生窗口处理，避免吞掉标题栏双击。屏幕位置使用物理坐标，支持不同缩放比例及负坐标屏幕。
- 设置 → 快捷键 → 便笺快捷键：新建、显示／隐藏、折叠／展开、停靠／取消停靠，全部默认未配置。显示／隐藏作用于所有已打开便笺；折叠和停靠作用于当前或最近使用的便笺。清除组合键即关闭对应快捷键，冲突时保留旧设置。
- 自动化回归覆盖草稿与编辑器保留、标题省略、双击折叠、悬停位置变化、左右圆角差异、恢复防重吸附、缩放及负坐标几何，以及开发／生产模式的样式与材质回退。真实屏幕边缘位置、原生材质和全局快捷键仍需 Windows 实机确认。
