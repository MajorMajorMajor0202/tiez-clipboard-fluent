便笺窗口与管理界面修复（2026-10-21）

- 独立窗口使用 `sticky-note-surface`，管理列表使用 `note-manager-card`，避免全局 CSS 同名规则互相污染。原先管理卡片的高度上限、内边距、悬停位移和强调色边框会同时作用于便笺窗口。
- 云母与亚克力通过 `set_note_backdrop` 调用原生材质，不改写主窗口主题；切换纯色时清除原生材质。不可用时保持可读的 CSS 背景。
- 标题栏在固定区域内淡入淡出，正文顶部留白保持固定。Markdown 与源码模式都不会因控件显隐移动文字。正文与控件间距缩小。
- 便笺创建时跳过任务栏，背景初始化也会修正已存在窗口的任务栏属性。
- 管理界面使用主界面相同的 Fluent 搜索框和中性按钮，卡片仅以中性色响应悬停，不上浮或突出强调色边框。

回归检查：`npm run test:notes`；生产构建及 CSP 检查：`npm run test:notes -- --release`。测试同时加载便笺窗口、管理界面和通用组件样式，覆盖原始样式冲突、材质成功与回退、显隐前后的编辑区尺寸与位置、220px 窄窗口按钮排布，以及管理界面搜索和新建操作。原生材质与任务栏行为需在 Windows debug 窗口中确认。
