# 本地数据可靠性修复（2026-10-19）

本轮处理本地数据管理与设置窗口启动。组件迁移现已恢复，范围见 FLUENT-MIGRATION.md。

- 工作区成员保存使用正确的 `value` 参数；主窗口串行保存快照，并在成功后读取数据库的正式 ID。启动时恢复旧版未能写入数据库的本地成员缓存。
- 工作区查询直接按成员 ID 在数据库中搜索、分页，避免先截断全局历史再过滤。普通剪贴板分页在 SQL 中排除便笺，避免空页。搜索读取完整内容，界面继续接收截断预览。
- 便笺与工作区成员不参与普通历史容量清理、清空及用后删除。关闭历史持久化时，将条目加入工作区仍会明确保存该材料，并将临时 ID 转为数据库 ID。
- 便笺从数据库加载成功后才挂载编辑器，停止使用旧的全文 localStorage 缓存。保存串行执行，关闭前等待最后一次输入落盘；写入失败显示错误并保留窗口。
- 单条、主窗口批量及标签批量删除遵守锁定保护。标签批量删除先检查所有条目；主窗口只移除实际删除成功的条目。显式删除会清理工作区引用。
- 同名旧标签向工作区的迁移在数据库事务中执行一次，保留原标签，扫描全部记录。
- 管理附件在仍有其他记录引用时保留；工作区元数据损坏时停止清理并返回错误。
- 设置窗口在数据与主题准备完毕、原生材质应用返回且等待首帧后才显示，再隐藏主窗口。创建完成事件不再直接显示透明窗口；隐藏 WebView 的动画帧等待有 100ms 超时保护。

## 验证与边界

新增 8 项临时数据库回归测试；前端新增便笺保存队列与设置窗口显示顺序测试。测试不操作实际用户数据库。

原有两项多显示器坐标测试失败：`keeps_bottom_right_anchor_when_switching_monitors` 和 `preserves_center_ratio_for_mid_screen_window`。已提取 HEAD 中的原函数和测试，独立编译复现相同失败。本轮未修改坐标算法。

工作区分页不预载全部条目正文；搜索按需逐条读取完整内容。附件删除需要检查其他记录引用，含附件的大批量清理会增加数据库读取开销，尚未做大型数据集性能测量。工作区成员仍使用 JSON 快照，多个窗口同时改写的事务合并可作为后续结构化表迁移事项。

设置窗口的自动化验证覆盖准备与显示的顺序，尚需在实际 Windows 桌面中目测冷启动与重复打开时的 DWM 合成效果。

## 设置启动后续修复

原先只等待主题和绘制后再显示，仍不足以覆盖隐藏窗口材质被 DWM 重置的情况。后续增加 HTML 入口实色背景（覆盖显式透明的设置层），显示后等待 150ms 再施加一次材质，绘制后才撤销实色背景。材质失败则保留实色界面；Rust 不再吞掉设置窗口的材质错误。浏览器测试覆盖模块加载前及主题 CSS 加载后的背景不透明性，实际桌面合成仍需目测。
